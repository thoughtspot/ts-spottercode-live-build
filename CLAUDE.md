# ThoughtSpot: Zero To Embed

This repo contains a sample NextJs application that can be used to replicate the content included in ThoughtSpot's "Build AI Analytics into Your App in 30 Minutes with Claude Code." Users of this repo should have access to a modern coding agent / assistant like Claude Code, Cursor, Codex, etc and should have ThoughtSpot's SpotterCode set up.

@AGENTS.md

## Rules

1. Follow coding best practices
2. Prefer clarity over cleverness
3. This is a React application, use React components from ThoughtSpot's Visual Embed SDK
